# MindLog AI

AIがユーザーの集中力や記憶定着率を分析・予測・支援する、パーソナライズ型学習管理・自己改善プラットフォームです。

## 使用技術スタック (Tech Stack)

- **Frontend:** Next.js, Tailwind CSS, Chart.js
- **Backend (API):** Java 17, Spring Boot, Spring Security (JWT)
- **AI/ML Engine:** Python 3.9, FastAPI
- **Database:** PostgreSQL
- **Infrastructure:** Docker / Docker Compose

## 概要

日々の学習時間や生活習慣、感情日記を記録し、AIが独自のインサイトと復習のベストタイミングを提案します。
